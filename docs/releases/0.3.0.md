# Review Workbench 0.3.0

本版改进审核导航、状态展示和整页批准，更新 README 桌面演示图片。

## 本版内容

- 放大“下一项”，支持 ← 返回上一项、→ 或空格进入下一项；输入框和对话框保留原有键盘操作，页面不再显示快捷键说明文字。
- 侧边栏展开、收起分别使用对应形状的图标，保持相同颜色，不用彩色底色表示展开状态。
- “🤖 修改依据”使用更大字体、蓝色文字和浅蓝底色，标题保持加粗。
- 条目和目录使用整块蓝色（待审）、绿色（已审）、红色（必审），当前所在位置以边框突出。
- 左上角全选图标直接批准本页，悬停提示“全选本页，跳过必审”。有建议的采用建议，无建议的保留原文；必审项、已有人工草稿和已提交条目跳过。
- 删除右侧批准按钮、各条目前的复选框和顶部重复的当前条目摘要。

## 下载哪个包

- **review-workbench-skill-0.3.0.zip**：供 AI 工作流安装或集成，包含 skill 与运行资源。
- **review-workbench-demo-0.3.0.zip**：六项未审核演示材料。完整解压后阅读 OPEN-ME.txt；Windows 可双击“开始校对.cmd”。无需 Git 或 AI skill。
- **SHA256SUMS.txt**：两个 ZIP 的 SHA-256 校验值。

需要 Python 3.11+，首次按包内说明安装 Python 依赖。演示含公式，提交公式决定还需 Node.js 18+。启动入口不会自动安装或下载。macOS 启动入口尚未在 macOS 真机运行验证。

协议 `schema_version` 仍为 `1`。已有 ZIP 不会自动更新，需重新导出才能获得本版界面。
