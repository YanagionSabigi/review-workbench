# Review Workbench 0.2.0

为其他 skill 提供本地人工校对界面，支持文字、术语、OCR、图片、公式与表格审核。

## 下载哪个包

- **review-workbench-skill-0.2.0.zip**：供 AI 工作流安装或集成。解压后的 `review-workbench/` 包含 SKILL.md、调用入口和运行资源。
- **review-workbench-demo-0.2.0.zip**：六项未审核演示材料，供人直接体验。完整解压后先阅读 OPEN-ME.txt；Windows 准备好依赖后双击“开始校对.cmd”。这个包不含 skill、示例源码或 Git 仓库。
- **SHA256SUMS.txt**：以上两个 ZIP 的 SHA-256 校验值。GitHub 自动提供的 Source code 是仓库源码。

需要 Python 3.11+，Python 依赖首次按包内说明安装。演示含公式，提交公式决定还需 Node.js 18+。收件人的审核包无需 Git；准备业务材料的完整工具仍需 Git。

## 本版内容

- 逐条审核与连续审核使用完整名称；连续审核移除无效的“下一项”按钮。
- 目录默认收起，顶部侧边栏图标支持展开/收起，悬停提示随状态变化。
- 桌面条目列表按需展开，窄屏减少导航占用；草稿比较展示实际内容，使用“本机版本 / 该文件版本”命名。
- 收件人包精简为审核运行所需文件，无公式时省去 KaTeX；启动直接运行本机服务，不自动安装或下载。
- 增加 Windows 双击启动入口和 macOS command 入口；启动步骤与依赖统一写入 OPEN-ME.txt，缺少依赖时保留提示。
- 提交、导入与冲突解决支持进程中断后的幂等恢复；比较发布前核验版本，拒绝覆盖较新的审核状态。

协议 `schema_version` 仍为 `1`，旧 Git 迁移包继续兼容。已有 ZIP 不会自动更新，需要重新导出以获得新界面及启动入口。macOS 启动入口尚未在 macOS 真机运行验证；Windows 启动器已实测。
